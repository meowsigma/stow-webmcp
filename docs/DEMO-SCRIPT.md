# 90-second demo script

Do not push this file until GitHub Pages has finished deploying.

1. Open https://meowsigma.github.io/stow-webmcp/ in Chrome with WebMCP enabled, or ChatGPT's in-app browser.
2. Show the Ryanair weekend bag, the red scale, TSA wine/lotion chips.
3. Pin the violin. Say: "I cannot leave this."
4. Click Watch a handoff, or ask the agent: "Propose a repack that keeps every pin."
5. Show the proposal does not drop the violin.
6. Accept. Scale drops. Seal if legal, or switch to Wildfire go-bag, add passport and meds, seal.
7. Show the manifest log attributing human vs agent.

Narration: Stow is a packing cockpit for humans and agents. WebMCP tools mutate the same bag you see. Pins are a veto the agent cannot override.
