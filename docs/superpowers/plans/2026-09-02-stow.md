# Stow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Every task has an Acceptance Contract; do not mark a task complete until its Quality Gate review returns PASS.

**Goal:** Ship Stow, a WebMCP packing cockpit where a human and an agent share one bag, with progressive tools, veto/pins, and a seal step.

**Architecture:** Pure TypeScript engine (trip, bag, rules, proposals) behind a vanilla Vite UI. Human clicks and `document.modelContext.registerTool` execute the same functions. Tool registration is aborted and rebuilt after every state change.

**Tech Stack:** Vite 5, TypeScript, Vitest, vanilla DOM, CSS custom properties, Chrome Labs WebMCP polyfill (native-first).
